# Eudi 的盲盒作品集

一个展示产品、产品运营、创业与设计实践的个人网站。首页有四只盲盒：每次新访问会随机分配主题，打开后显示内容，返回地图会保留本次浏览的已拆状态。

## 页面

- 关于 Eudi：个人特点、能力与创新观点
- 得物产品运营实习：格叽在线共创拼豆平台的产品需求与运营实践
- 创业作品：原创娃衣品牌与包叽饺叽 IP
- 设计作品：娃衣、周边、海报与角色视觉

## 本地运行

项目是静态 HTML、CSS 和 JavaScript，无需安装依赖。在项目目录执行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 网站链接

当前 Sites 版本为私有访问。准备对外分享时，应先将站点访问权限改为公开，再把公开链接写在这里。
